Análisis de microbiomas con phyloseq + vegan

La inferencia estadística parte de un principio fundamental: no observamos la población completa, sino una muestra, y a partir de ella estimamos parámetros y contrastamos hipótesis sobre la estructura poblacional. En estudios de microbioma, este proceso suele ser multivariado: cada muestra está descrita por un vector de abundancias de múltiples taxones, y las comparaciones entre comunidades suelen realizarse mediante métricas de disimilitud. Así, la inferencia puede involucrar tanto estimadores de diversidad dentro de muestras (diversidad alfa) como diferencias estructurales entre comunidades (diversidad beta). En este taller aplicaremos estos principios utilizando el dataset GlobalPatterns, incluido en el paquete phyloseq, que integra abundancias 16S, taxonomía, metadatos y árbol filogenético en un único objeto estructurado. A partir de este ejemplo, desarrollaremos análisis descriptivos y pruebas inferenciales que permitan interpretar la estructura comunitaria en distintos tipos de ambientes.

NotaObjetivos

Se desarrollarán cuatro bloques principales:

  1. Análisis composicional (Top 15 familias y géneros).
  2. Análisis de ordenación (PCA y PCoA).
  3. Análisis de diversidad alfa y beta.

SampleType será la variable categórica para comparar grupos

II. Análisis composicional a nivel de Familia

La unidad de análisis puede definirse a distintos niveles de resolución. Podemos trabajar con ASVs individuales, que ofrecen máxima resolución taxonómica (en el caso de 16S), o bien agruparlos en niveles más agregados (por ejemplo, Familia o Género). Agrupar taxones equivale a sumar sus abundancias dentro de cada muestra.

  1. Para realizar esta agregación a nivel de Familia utilizamos la función tax_glom() del paquete phyloseq, que colapsa los ASVs pertenecientes a la misma categoría taxonómica:
ps_fam <- tax_glom(ps, taxrank = "Family", NArm = TRUE)
  1. Ahora, podemos identificar las 15 familias más abundantes en el dataset y visualizarlas usando plot_bar:
top15_fam <- names(sort(taxa_sums(ps_fam), decreasing = TRUE))[1:15] #Identifica las familias más abundantes globalmente.
ps_fam_top <- prune_taxa(top15_fam, ps_fam) #Filtra el dataset para quedarse solo con ellas.
ps_fam_top_rel <- transform_sample_counts(ps_fam_top, function(x) x / sum(x)) #Convierte los conteos a abundancia relativa por muestra.
  1. Visualiza la composición de las familias más abundantes por tipo de muestra. Se usa SampleType.
plot_bar(ps_fam_top_rel, x = "SampleType", fill = "Family") +
theme_bw() +
labs(
y = "Abundancia relativa",

) +

III. Análisis de ordenación

  1. Para analizar la estructura global de las comunidades microbianas y cómo se relacionan entre sí, podemos realizar análisis de ordenación como PCA o PCoA. Primero, necesitamos transformar los datos a abundancia relativa para evitar que las diferencias en el número total de secuencias por muestra afecten el análisis:
ps_gen <- tax_glom(ps, taxrank = "Genus", NArm = TRUE) #Este es el objeto que ud había creado para el análisis composicional a nivel de género.
ps_gen_rel <- transform_sample_counts(ps_gen, function(x) x / sum(x))

X <- t(as(otu_table(ps_gen_rel), "matrix")) #Extrae la tabla de abundancias, la convierte en una matriz estándar de R, transpone la matriz.

  1. Ahora sí vamos a hacer un PCoA usando brays-curtis como medida de distancia entre las muestras. Para esto, se puede usar la función vegdist para calcular la matriz de distancias y luego cmdscale para realizar el PCoA:
bray <- vegdist(X, method = "bray") #Calcula la matriz de distancias entre las muestras utilizando la distancia de Bray-Curtis, que es una medida comúnmente utilizada en ecología microbiana para comparar la composición de comunidades.

Ahora se extraen las coordenadas de las muestras en el espacio de ordenación y se combinan con los metadatos para facilitar la visualización

Finalmente, se puede visualizar el resultado del PCoA usando ggplot2 para crear un gráfico de dispersión donde cada punto representa una muestra y el color indica el tipo de muestra (SampleType):

ggplot(df_pcoa, aes(PCoA1, PCoA2, color = SampleType))
  1. Par ver qué géneros contribuyen más a la separación de las muestras en el espacio de ordenación, se puede usar la función envfit del paquete vegan, que ajusta vectores de variables (en este caso, géneros) al espacio de ordenación:
set.seed(1) #Para asegurar la reproducibilidad del análisis de permutaciones en envfit
fit <- envfit(pcoa$points, X, permutations = 999) #Ajusta los vectores de los géneros al espacio de ordenación utilizando permutaciones para evaluar la significancia de cada vector.

tax_fit <- as.data.frame(fit$vectors$arrows) #Extrae las coordenadas de los vectores ajustados por envfit.

tax_fit$Genus <- rownames(tax_fit) #Agrega una columna con los nombres de los géneros correspondientes a cada vector.

top_taxa_pcoa <- tax_fit[order(tax_fit$r2, decreasing = TRUE), ][1:15, ] #Ordena los géneros por su valor de R² y selecciona los 15 más importantes para la visualización.

alpha$SampleType <- sample_data(ps)$SampleType #Agrega una columna con el tipo de muestra correspondiente a cada muestra.

En el apartado III se realizó un análisis de ordenación (PCoA) basado en la distancia de Bray-Curtis, que es una medida de diversidad beta, pero no se hizo un análisis estadístico para comparar la diversidad beta entre los diferentes tipos de muestras. Para esto, se puede usar la función adonis del paquete vegan, que realiza un análisis de permutación para evaluar si las diferencias en la composición de las comunidades microbianas entre los grupos (en este caso, SampleType) son estadísticamente significativas:
adonis2(bray ~ SampleType, data = meta) #Ejecuta una PERMANOVA (Permutational Multivariate Analysis of Variance).
bd <- betadisper(bray, meta$SampleType) #Evalúa la homogeneidad de dispersión multivariada entre grupos.
anova(bd) #Realiza un análisis de varianza para comparar la dispersión entre los grupos.
